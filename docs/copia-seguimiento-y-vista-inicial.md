# Compartir seguimiento y vista inicial

Los botones seleccionan el campo y copian el contenido. Primero se intenta la copia compatible con navegadores de kiosco (también en HTTP) y después Clipboard API. Si el navegador bloquea ambas, queda seleccionado el enlace o el mensaje y se explica cómo copiarlo manualmente. Nunca se confirma una copia que no haya terminado correctamente.

Se muestra un enlace navegable al seguimiento y un mensaje con URL absoluta en una línea propia, sin puntuación final. «Abrir WhatsApp» abre wa.me con el mensaje codificado; no elige destinatario ni envía mensajes. WhatsApp decide cómo presenta las direcciones; no existe un formato de portapapeles que obligue a esa aplicación a hacerlas clicables. El enlace conserva el token en el fragmento y los permisos, vigencia y revocación actuales.

«Pedidos WEB» es la primera pestaña y la vista inicial. La primera consulta y los refrescos usan WEB, todos los estados, delegaciones permitidas y un mes de fechas inicial. Las otras pestañas siguen siendo seleccionables.
