# Importes por línea de albarán

El detalle muestra Precio (Precio de EXIT), % descuento ([%Descuento]), Precio neto (ImporteNeto) y Total (ImporteLiquido). Se conservan además artículo, delegación y cantidad. Los valores provienen de cada línea original de EXIT; no se recalculan en el navegador ni se sustituye ImporteNeto por BaseImponible cuando vale cero.

Los usuarios sin permiso para ver precios siguen recibiendo estos campos ocultos por la API y ven asteriscos, también en el descuento. En pantallas estrechas la tabla permite desplazamiento horizontal. Sin cambios de esquema.
