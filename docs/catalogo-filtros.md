# Búsqueda dentro de una categoría

La selección de departamento, familia, subfamilia y tipo de producto se combina con el texto del buscador (producto, marca, referencia o medida).

- Escribir, enviar la búsqueda o usar el teclado en pantalla conserva la categoría seleccionada.
- Cambiar la categoría conserva el texto. Se reinician solo los niveles inferiores que dejan de corresponder a la nueva selección.
- Las sugerencias aplican los mismos filtros de clasificación y visibilidad que los resultados. Elegir una sugerencia conserva el filtro genérico actual; no lo sustituye por la clasificación completa del producto.
- La cruz del buscador o de la etiqueta de búsqueda borra solo el texto.
- Las etiquetas de categoría permiten quitar ese nivel o regresar al nivel anterior, conservando el texto.
- «Limpiar filtros» borra texto y clasificación, cierra las sugerencias y vuelve a la primera página del catálogo completo permitido al cliente.

No se modifican las reglas de búsqueda de EXIT ni las categorías visibles configuradas por el operador.
